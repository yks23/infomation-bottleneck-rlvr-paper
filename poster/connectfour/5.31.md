# 5.31 实验记录

## 实验1：自博弈 vs 固定对手

**目的**

验证 self-play 是否比固定弱对手更能维持有效训练信号，并避免训练分布塌缩。

**预期**

self-play 应该比固定随机对手、固定 weak-MCTS 对手更稳，泛化性能更好。

**结果**

| 设置 | random win mean | weak-MCTS win mean | final random win | final weak-MCTS win |
| --- | --- | --- | --- | --- |
| self-play | 0.886 | 0.625 | 0.948 | 0.833 |
| fixed random | 0.778 | 0.573 | 0.760 | 0.667 |
| fixed weak-MCTS | 0.804 | 0.458 | 0.854 | 0.833 |

固定对手组的梯度和参数更新更大：

| 设置 | grad_l2 mean | param_delta_l2 mean |
| --- | --- | --- |
| self-play | 0.869 | 0.085 |
| fixed random | 1.983 | 0.095 |
| fixed weak-MCTS | 2.687 | 0.095 |

**结论**

符合预期。self-play 是最稳的主训练方式。固定对手虽然带来更大的更新范数，但没有带来更好的策略质量，说明"更新大"不等于"有效学习"。

## 实验2：奖励噪声影响

**目的**

比较 Gaussian / Uniform 奖励噪声对信息量、奖励分离度和最终性能的影响。

**预期**

轻微噪声可能改善探索；噪声过大可能破坏学习。

**结果**

| 设置 | random win mean | weak-MCTS win mean | mean I_acc | mean S_rel |
| --- | --- | --- | --- | --- |
| self-play no noise | 0.886 | 0.625 | 0.893 | 0.990 |
| Gaussian 0.05 | 0.879 | 0.677 | 0.891 | 0.990 |
| Gaussian 0.1 | 0.900 | 0.615 | 0.899 | 0.999 |
| Gaussian 0.2 | 0.893 | 0.604 | 0.890 | 1.018 |
| Uniform 0.05 | 0.882 | 0.635 | 0.895 | 0.990 |
| Uniform 0.1 | 0.888 | 0.583 | 0.888 | 0.997 |
| Uniform 0.2 | 0.895 | 0.719 | 0.898 | 1.023 |

**结论**

部分符合预期。噪声没有明显破坏训练，Uniform sigma=0.2 对 weak-MCTS 的平均胜率最高，达到 0.719。但由于只有 300 steps 和 3 seeds，这更适合作为趋势，而不是严格显著结论。

## 实验3：参数更新范数与信息指标关系

**目的**

验证 param_delta_l2 / grad_l2 是否和 I_acc、结果熵、奖励分离度正相关。

**预期**

信息量高时，参数更新应更大；信息量低时，更新变小。

**结果**

| 设置 | corr(param_delta, I_acc) |
| --- | --- |
| self-play | 0.016 |
| fixed random | -0.028 |
| fixed weak-MCTS | -0.033 |
| Gaussian 0.05 | 0.003 |
| Gaussian 0.1 | -0.019 |
| Gaussian 0.2 | -0.012 |
| Uniform 0.05 | -0.033 |
| Uniform 0.1 | -0.005 |
| Uniform 0.2 | -0.029 |
| opponent noise 0.05 | -0.002 |
| opponent noise 0.1 | -0.035 |
| shaping | 0.040 |

**结论**

不符合预期。当前数据没有支持"更新范数与信息量正相关"。主要原因可能有两个：

1. 当前 `I_acc = H_bits * S_rel / (S_rel + eps)`，当 S_rel > 0 时几乎退化成 H_bits。
2. 300 steps 较短，同步相关可能看不到滞后学习效果。

后续应改用更有区分度的指标，例如：

```
I_acc_v2 = H_bits * log1p(S_rel)
```

或者：

```
I_acc_v2 = H_bits * S_rel / (S_rel + c)
```

其中 c 应取实验经验尺度，而不是极小 eps。

## 实验4：对手动作扰动

**目的**

检验给对手策略加入随机动作扰动是否能维持较高信息熵并改善训练。

**预期**

适度扰动可能提升熵和泛化；过强扰动会引入噪声。

**结果**

| 设置 | random win mean | weak-MCTS win mean | grad_l2 mean |
| --- | --- | --- | --- |
| self-play | 0.886 | 0.625 | 0.869 |
| opponent noise 0.05 | 0.810 | 0.531 | 2.803 |
| opponent noise 0.1 | 0.785 | 0.573 | 2.803 |

**结论**

不符合预期。对手动作扰动降低了训练质量。虽然更新范数变大，但性能下降，说明扰动更多是在增加训练噪声，而不是提供更有价值的信息。

## 实验5：二元终局奖励 vs 过程奖励

**目的**

验证过程 reward shaping 是否能提高奖励分离度和训练稳定性。

**预期**

过程奖励应提升策略区分度，从而改善学习。

**结果**

| 设置 | random win mean | weak-MCTS win mean | mean I_acc | mean S_rel |
| --- | --- | --- | --- | --- |
| terminal binary | 0.886 | 0.625 | 0.893 | 0.990 |
| terminal + shaping | 0.864 | 0.750 | 0.896 | 0.990 |

**结论**

部分符合预期。Shaping 没有显著提升 random win rate，但明显提高了对 weak-MCTS 的平均胜率，0.750 vs 0.625。说明轻量过程奖励可能改善对中等强度对手的泛化。

## 实验6：Reward Information 指标比较

**目的**

比较多种 reward information 定义能否解释 fixed-reference task deficit 的下降，并回答：在 AlphaZero-like Connect Four 任务中，什么量更适合作为 reward information？一个好的 reward information 指标应该既不是退化常数，又能区分训练机制，还能比旧指标和优化强度指标更好地解释 fixed-reference performance progress。

**预期**

terminal reward variance 可能太粗；reward-backed Q variance 应比 terminal variance 更有信息；performance-indexed `var * dp` 可能比 raw variance 更能解释能力提升；absorbed policy-search information 可能比 absorbed reward 更强。

**实验设置**

- 环境：OpenSpiel `connect_four`
- 规模：5 conditions x 3 seeds x 300 learner steps，共 15 runs
- 条件：`self_play`、`terminal_plus_shaping`、`uniform_reward_noise=0.2`、`opponent_action_noise=0.1`、`fixed_random`
- fixed reference pool：weak / mid / strong checkpoints
- 分析目标：fixed-reference win rate 与 task deficit

固定 reference 评估中，当前模型与 reference 对弈，得到：

```
p_t^r = P(pi_theta_t beats pi_ref^r)
D_t^{r,q} = max(0, logit(q) - logit(p_t^r))
```

主要使用 `q=0.5`。比较的候选指标包括：

| 指标 | 含义 |
| --- | --- |
| `terminal_reward_var_train` | self-play 终局 reward `z` 的方差 |
| `reward_action_var_q_mcts` | MCTS backup 的 `Q(s,a)` 在动作维度上的方差 |
| `action_value_var_dp_pos` | action-value variance 沿 fixed-reference 胜率提升 `dp` 的累计 |
| `absorbed_reward_pos` | value/reward loss 的单步下降累计 |
| `absorbed_policy_pos` | policy KL 的单步下降累计 |
| `absorbed_combined_pos` | reward + policy combined loss 的下降累计 |
| `grad_l2` / `param_delta_l2` | 优化强度指标 |
| `H_bits` / `I_acc` / `S_rel` | 之前实验中的信息量候选指标 |

**结果**

self-play-like 条件下，terminal reward variance 几乎恒定：

| condition | terminal reward variance |
| --- | ---: |
| self_play | 0.9945 |
| terminal_plus_shaping | 0.9952 |
| uniform_reward_noise=0.2 | 1.0230 |

MCTS action-value variance 更能区分训练条件：

| condition | `reward_action_var_q_mcts` |
| --- | ---: |
| self_play | 0.0181 |
| terminal_plus_shaping | 0.0189 |
| uniform_reward_noise=0.2 | 0.0182 |
| opponent_action_noise=0.1 | 0.0813 |
| fixed_random | 0.1133 |

对于 `q=0.5` 的 future deficit drop，跨 condition/reference 平均后，最强的是 performance-indexed var-dp：

| metric | k=1 R2 / Spearman | k=3 R2 / Spearman | k=5 R2 / Spearman |
| --- | ---: | ---: | ---: |
| `action_value_var_dp_pos` | 0.568 / 0.761 | 0.314 / 0.503 | 0.262 / 0.452 |
| `terminal_train_var_dp_pos` | 0.561 / 0.757 | 0.322 / 0.514 | 0.279 / 0.482 |
| `absorbed_reward_pos` | 0.014 / 0.046 | 0.033 / 0.109 | 0.047 / 0.127 |
| `absorbed_policy_pos` | 0.013 / 0.053 | 0.014 / 0.052 | 0.011 / -0.007 |
| `absorbed_combined_pos` | 0.016 / 0.052 | 0.032 / 0.107 | 0.044 / 0.100 |

旧指标和优化强度指标也较弱。对于 `q=0.5, k=1`，`I_acc` 和 `H_bits` 平均 R2 只有 0.024，远低于 var-dp 指标。`grad_l2` 和 `param_delta_l2` 只能反映 update intensity，不能可靠表示 transfer 到 fixed-reference performance。

Condition summary：

| condition | final weak | final mid | final strong | Q var | action var-dp | absorbed reward | absorbed combined |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| self_play | 0.167 | 0.167 | 0.167 | 0.0181 | 0.0506 | 4.4967 | 8.0505 |
| terminal_plus_shaping | 0.000 | 0.000 | 0.167 | 0.0189 | 0.0740 | 4.5270 | 8.2687 |
| uniform_reward_noise=0.2 | 0.333 | 0.000 | 0.000 | 0.0182 | 0.0851 | 5.2541 | 8.9265 |
| opponent_action_noise=0.1 | 0.333 | 0.000 | 0.167 | 0.0813 | 0.1930 | 20.7320 | 25.3310 |
| fixed_random | 0.333 | 0.333 | 0.000 | 0.1133 | 0.2526 | 13.7418 | 18.5828 |

**结论**

部分符合预期。terminal reward variance 确实太粗，在 self-play-like 条件下近似常数，只能作为 feedback non-degeneracy 指标。Q action-value variance 更能反映 reward 在动作选择层面的区分度，也更能区分不同训练条件。

但 raw Q variance 高不等于 transfer 好。`opponent_action_noise=0.1` 和 `fixed_random` 的 Q variance、absorbed reward、absorbed combined 都很高，却没有稳定提升 reference win rate，说明存在明显的 training information 与 target transfer mismatch。当前最有解释力的是 `var * dp`，也就是 reward/action variance 沿 fixed-reference performance axis 的累计：

```
sum_t V_t * delta_p_t
```

absorbed reward / policy / combined loss reduction 没有解释 fixed-reference improvement，absorbed policy-search information 也没有强于 absorbed reward。

## 实验7：Training-free / Path-independence First-passage

**目的**

检验更强的 training-free 假设：对于同一个基础模型、同一个固定 reference、同一个目标胜率，模型达到该水平所需累计的 reward information 是否近似固定，与训练路径无关。

形式化地说：

```
I_R(p0 -> q) = integral_{p0}^{q} v_R(p) dp
```

这次不是预测 future deficit drop，而是测试 first-passage path independence。

**预期**

如果 training-free 假设成立，那么好的 reward information density `v_R(p)` 应满足：不同训练路径的曲线近似重合，first-passage integral CV 很低，conditional CV `CV(v | p)` 很低，控制 `p` 后 condition effect 很小，loop integral 接近 0。

如果不成立，即使达到同样 fixed-reference win rate，不同训练路径的 Q-based reward information 仍然不同。

**实验设置**

- 固定初始 checkpoint：`runs/reference_pool/base_init.pt`
- reference：weak / mid / strong
- evaluator：stochastic sampling，512 games
- paths：`self_play`、`terminal_plus_shaping`、`uniform_reward_noise=0.2`、`opponent_action_noise=0.1`、`fixed_random`、`lr=1e-3`、`MCTS rollouts=32`

比较四类候选 density：

| candidate | 定义 | 作用 |
| --- | --- | --- |
| `ref_p_1mp` | `p(1-p)` | 正对照，天然 path-independent |
| `terminal_var_z_train` | `Var(z_t)` | 粗粒度 terminal reward variance |
| `q_var_train` | 训练分布上的 `E_s Var_a Q(s,a)` | 路径相关的 Q variance |
| `q_var_probe` | 固定 probe set 上的 `E_s Var_a Q(s,a)` | 主要的非平凡 training-free 候选 |

**结果**

只有 weak reference、`q=0.5` 有足够 first-passage 样本。`q=0.7` 以及 mid/strong reference 没有足够路径达到目标。

First-passage integral CV：

| candidate | CV | mean |
| --- | ---: | ---: |
| `ref_p_1mp` | 0.117 | 0.0309 |
| `terminal_var_z_train` | 0.208 | 0.1171 |
| `q_var_train` | 0.807 | 0.0031 |
| `q_var_probe` | 1.329 | 0.0059 |

按 condition 看，`q_var_probe` 在 self-play-like paths 内较稳定，但在 mismatch 条件中高一个数量级：

| condition | `q_var_probe` first-passage integral |
| --- | ---: |
| self_play | ~0.00268 |
| terminal_plus_shaping | ~0.00262 |
| uniform_reward_noise=0.2 | ~0.00328 |
| lr=1e-3 | ~0.00267 |
| MCTS rollouts=32 | ~0.00197 |
| opponent_action_noise=0.1 | ~0.01854 |
| fixed_random | ~0.02725 |

Conditional CV：

| candidate | mean CV | median CV |
| --- | ---: | ---: |
| `q_var_probe` | 0.829 | 0.811 |
| `q_var_train` | 0.735 | 0.818 |
| `ref_p_1mp` | 0.016 | 0.014 |
| `terminal_var_z_train` | 0.248 | 0.251 |

控制 `p` 后，不同 condition 的影响仍然明显：

| candidate | condition_effect_range |
| --- | ---: |
| `q_var_probe` | ~0.153-0.158 |
| `q_var_train` | ~0.073-0.078 |
| `ref_p_1mp` | ~0.001 |

Loop residual：

| candidate | mean abs loop residual |
| --- | ---: |
| `q_var_probe` | 0.0020 |
| `q_var_train` | 0.0020 |
| `ref_p_1mp` | 0.0029 |
| `terminal_var_z_train` | 0.0139 |

loop residual 较小，说明没有明显循环积分异常。但由于 Q variance 数值本身很小，loop test 不能单独证明路径无关。主要证据仍然是 first-passage CV、conditional CV 和 condition effect。

**结论**

不符合全局 training-free 预期。`p(1-p)` 最稳定，但它只是由 fixed-reference win rate 直接决定的 positive control。`terminal_var_z_train` 相对稳定，但主要因为 terminal reward variance 本身接近常数，语义太粗。

非平凡的 Q-based reward information 没有通过 path-independence 检验。`q_var_train` 和 `q_var_probe` 的 first-passage integral CV 都很高；控制 performance 后，训练路径仍然显著影响 Q variance。这说明同样的 fixed-reference 胜率可以由不同的 internal reward/action-value structure 达到。

更准确的判断是：reward information 不是全局 training-free 标量；它只在 self-play / shaping / uniform noise / lr / rollout 这些相近 self-play-like training family 内近似稳定。跨 fixed opponent / opponent noise 时，training distribution 和 search/opponent mismatch 会显著改变 reward/action-value structure。

## 总体结论

1. Connect Four 比 TicTacToe 更适合作为信息瓶颈实验环境，训练差异明显得多。
2. self-play 是最稳的训练基线，固定对手不适合作为主训练协议。
3. 奖励噪声在当前尺度下可承受，Uniform sigma=0.2 有一定正向趋势。
4. 对手动作噪声没有带来预期收益，反而降低训练质量。
5. 过程奖励 shaping 在 8h evaluator 中对 weak-MCTS 泛化有帮助，但在 10h fixed-reference evaluator 中没有稳定复现，需要区分 evaluator 设置。
6. 胜率 `p_t` 不能直接当作 reward random variable；terminal reward variance 在 self-play-like 设置下近似恒定，只能表示反馈通道没有退化。
7. Q action-value variance 比 terminal reward variance 更能反映 reward 在动作选择上的区分度，但 raw Q variance 会混入训练分布、对手和 search mismatch。
8. `var * dp` 是当前最有解释力的 performance-indexed accounting measure，但它包含 `delta_p_t`，更适合作为沿性能轴的归一化记账量，而不是独立预测器。
9. gradient norm、param_delta_l2、absorbed reward / policy / combined loss reduction、旧 `I_acc` 都不是稳定的主解释变量。
10. 非平凡 reward information 不是全局 training-free 的；fixed-probe Q variance 只在相近 self-play-like paths 上有一定 invariance。
11. fixed_random 和 opponent_action_noise 产生了更高的 Q variance 和 absorbed reward，但没有稳定带来 reference generalization，说明高训练信息不等于高 transfer。
12. reward information 更像是 task-level component、training distribution component、search/opponent mismatch component 的混合，而不是单一 training-free 标量。
